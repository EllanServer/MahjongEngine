# 牌桌信息与交互层级

本项目把牌桌反馈限制为“一类信息只占一个主通道”，避免 Minecraft 的 BossBar、ActionBar、聊天与世界文字同时重复同一句话。

| 层级 | 主通道 | 内容 | 持续方式 |
|---|---|---|---|
| 常驻状态 | BossBar | 局次、当前玩家、剩余牌 | 状态改变时更新 |
| 当前决策 | 自己手牌旁的私有提示与按钮 | 出牌、吃碰杠荣、国标“亮花”、四川定缺 | 决策窗口结束即消失 |
| 公共事件 | 桌心短公告 | 吃、碰、杠、立直、自摸、荣和；多荣合并显示 | 普通动作 2 秒，和牌 3 秒 |
| 结算 | 结算背包 UI | 役种、番符、支付、点数变化 | 玩家关闭或准备下一局 |
| 异常与管理 | 聊天 | 错误、权限、命令结果、离线警告 | 保留聊天记录 |
| 声音 | 定向/公共音效 | 自己回合定向提示；牌、鸣牌、和牌公共反馈 | 同一事件指纹只播放一次 |

具体约束：

- 入座玩家不再显示与 BossBar 重复的详细中心私有面板；观战者仍保留详细面板。
- 决策提示不再逐字重复按钮标签，也不再镜像到 ActionBar 和聊天。
- 桌心临时动作覆盖常驻状态，而不是在其下方继续追加文字。
- 座位信息保持单行；玩家名、动作按钮与决策文字按中英文/表情符号视觉宽度裁切。
- 多家荣和从最终 `RoundResolution` 的实际赢家集合生成，不使用最后提交反应的玩家。
- 右侧“看牌河”与俯视状态下“返回座位”是独立操作按钮，不受提示精简影响。

公开产品参考：

- [雀魂 App Store 官方页面](https://apps.apple.com/ca/app/mahjong-soul/id1464872167)：对局截图将桌面常驻信息、手牌区和可执行动作分区，结算使用独立画面。
- [天凤官方手册](https://cdn.tenhou.net/man/)：吃碰杠/荣与自动操作使用专门控件，和牌/流局使用短时字幕，而非聊天滚屏。
- [Maru-Jan 官方对局截图](https://www.maru-jan.com/screenshot_marujan.html)：当前动作按钮靠近手牌，计时与常驻状态放在固定区域。

这些参考只用于信息层级与交互节奏，不复用其图形、声音或其他素材。
