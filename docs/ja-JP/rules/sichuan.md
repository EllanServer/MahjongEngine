# 四川麻雀（T/TFMJ 血戦到底）

[日本語ドキュメント](../README.md) | [インストール](../installation.md) | [リーチ麻雀](./riichi.md) | [国標麻雀](./gb.md) | **四川麻雀**

`SICHUAN` は、四川天府新区麻雀運動協会の T/TFMJ 01—2024『四川麻雀競技規則』を規範とする四人血戦到底 profile です。MIL や「天府龍牌」の地方大会規則は比較資料であり、既定 profile へ混在させません。

## 基本仕様

| 項目 | 既定動作 |
| --- | --- |
| 牌 | 萬・筒・索のみ 108 枚 |
| 開局 | 配牌後に直接定欠。換三張なし |
| 鳴き | ポン、明槓、暗槓、加槓。チーなし |
| 和了 | 血戦到底。和了者を除いて続行 |
| 基本形 | 四面子一雀頭、または七対 |
| fan | 平胡 0、対々胡 1、清一色 / 七対 2、合計 3 fan 上限 |
| 支払い | ロン `2^fan`、ツモは各活動相手が `2^fan + 1` |
| 一室の長さ | 既定 8 副。完全な大会レイヤーは未実装 |

## 配牌、サイコロ、定欠

親は 14 枚、他家は 13 枚で開始します。開門は一組の二個サイコロだけを使い、合計で開門する辺を、低い方の目で幢数を決めます。ゾロ目ならその目を使います。槓の補充牌は残り牌山の後方から取得します。

配牌後、全員が萬・筒・索の一種類を定欠します。T/TFMJ profile には強制換三張がありません。

- 定欠牌が手牌に残る間は、その種類を優先して捨てます。
- 定欠牌を暗手または副露に含む形では和了できません。
- 入力時間切れ時は、手牌に基づく決定的な合法選択を行います。

## 通常手番と血戦到底

- 通常は一枚摸って一枚捨てます。
- チーはできません。
- ロンはポン・明槓より優先し、一つの捨て牌で複数ロンが成立します。
- 加槓の四枚目は、その手番で摸った牌でなければなりません。成立前に搶槓できます。
- 各槓は補充牌が残る場合だけ成立します。

最初の和了で一副は終わりません。和了者は即時精算され、その副の活動対象から外れます。残るプレイヤーは同じ牌山と得点で続行し、三人目が和了するか、牌山が尽きると終了します。

## 過胡と牌山末段

和了を見送った場合、本人が次に摸牌するまで、同じまたは低い fan の和了はできません。より高い fan なら和了できます。ロン可能時にポンまたは槓を選んだ場合も同じです。比較はツモ支払いの `+1` より前の fan を使い、0 fan と 1 fan を別段階として扱うため、平胡を見送った後の 1 fan 対々胡は許可されます。

T/TFMJ には「最後四枚は必ず和了」という規則がありません。

- ロンやツモを見送れます。
- 補充牌がある限り、合法なポン・槓を残り四枚だけを理由に全面禁止しません。
- タイムアウト処理は和了を強制しません。
- 実際の最後の牌、またはその最後の捨て牌だけが海底になります。

## fan と支払い

基本形は最も高い一項を採用し、加算要素を重ね、支払い用合計を 3 fan で上限化します。

| 要素 | fan | 説明 |
| --- | ---: | --- |
| 平胡 | 0 | 基本 1 点 |
| 対々胡 | 1 | 四組の刻子 / 槓子と雀頭 |
| 清一色 | 2 | 一種類の数牌だけ |
| 七対 | 2 | 門前の七組対子 |
| 根 | +1 / 組 | 同一牌四枚。七対内でも加算 |
| 金鉤釣 | +1 | 四副露後の単騎待ち |
| 槓上花 | +1 | 槓補充牌でツモ |
| 槓上炮 | +1 | 槓直後の捨て牌で放銃 |
| 搶槓 | +1 | 加槓牌でロン |
| 海底 | +1 | 最終牌またはその捨て牌で和了 |

将対、龍七対、双龍七対、豪華龍七対は T/TFMJ の独立 fan ではありません。2・5・8 だけの刻子形は対々胡、四枚を含む七対は `七対 + 根` と表示します。

```text
基本単位 P = 2^min(fan, 3)   // 1, 2, 4, 8
ロン: 放銃者が P
ツモ: 各活動相手が P + 1
```

複数ロンでは放銃者が各和了者の `P` を個別に支払います。すでに和了したプレイヤーは、その後の和了・槓・荒牌支払いに参加しません。

## 槓点と呼叫転移

- 暗槓：他の活動プレイヤーが各 2。
- 明槓：槓牌を捨てたプレイヤーだけが 2。
- 加槓：他の活動プレイヤーが各 1。

槓をしたプレイヤーが直後に放銃した場合、その槓と連続槓で得た全収入を和了者へ移す「呼叫転移」を行います。元の支払者へは返しません。複数ロンでは各和了者へ `ceil(連続槓収入 / 和了者数)` を渡し、割り切れない差額を放銃者が補います。槓後の通常捨て牌で誰も和了しなければ、その連続槓 chain は終了します。

## 荒牌、査叫、天然花猪

牌山が尽きた時点で、活動プレイヤー全員の実際の手牌と副露から聴牌を再計算します。物理的に存在しない第五枚は待ちにしません。

- 定欠牌を自然に残したプレイヤーは未聴として査叫へ参加します。
- 最終手牌だけから固定 16 / 48 点の花猪罰を作りません。
- 各未聴者は、各聴牌者へその人の最高理論単位（最大 8）を支払います。
- 未聴者がその副で得た槓収入は、査叫前に元の支払者へ返します。

実大会の違反花猪は審判記録を必要とする外部罰です。通常の荒牌 snapshot だけから推定できません。

## 一室の長さと次の親

T/TFMJ は一局を通常 50 分または 8 副とし、大会要項で 6 副などへ変更できます。MahjongPaper は既定 8 副を実装し、純得点 0 から表示します。8 局 × 8 副の完全な優勝大会レイヤーや時間終了処理はまだ実装していません。汎用点数・長さ設定を変更した卓はカスタムルームです。

- 最初の和了者が次副の親。
- 最初の和了が複数ロンなら放銃者が親。
- 和了者がいなければ現在の親を維持。

既定 UI はリーチ麻雀の「東一～南四」を流用せず、**第1副～第8副** と表示します。親の位置は副数とは別に管理します。

## 主な操作

| 操作 | コマンド |
| --- | --- |
| 四川モード | `/mahjong mode SICHUAN` |
| ツモ / ロン | `/mahjong tsumo` / `/mahjong ron` |
| ポン / 明槓 | `/mahjong pon` / `/mahjong minkan` |
| 暗槓・加槓 | `/mahjong kan <tile>` |
| 反応を見送る | `/mahjong skip` |
| 直近の結果 | `/mahjong settlement` |

`/mahjong chii` は使用できません。配牌後はゲーム内案内から定欠だけを選びます。
