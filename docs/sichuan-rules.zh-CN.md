# 四川血战麻将玩家规则

[English](./sichuan-rules.md) · [日本語](./ja-JP/rules/sichuan.md)

> **规范基线：** `SICHUAN` 以四川天府新区麻将运动协会发布的 T/TFMJ 01—2024《四川麻将竞赛规则》为裁决依据。MIL 与“天府龙牌”等地方赛事规则只作差异对照，不混入默认 profile。

## 快速查表

| 项目 | 当前插件规则 |
| --- | --- |
| 人数 | 固定 4 人 |
| 牌数 | 108 张纯序数牌；无字牌、花牌、赤牌 |
| 起手 | 庄家 14 张，其余玩家 13 张 |
| 开局 | 发牌后直接定缺；默认不换三张 |
| 动作 | 碰、大明杠、暗杠、加杠、荣和、自摸；不能吃 |
| 和牌流程 | 血战到底：和家退出本手，其余玩家继续 |
| 和牌牌型 | 四面子一对或七对，且定缺花色必须清空 |
| 支付 | `2^min(番数, 3)`；自摸每名付款者再加 1 底分 |
| 赛长 | 房间默认 8 副；完整官方赛事层尚未实现 |

## 1. 牌组与发牌

牌墙只有万、筒、索 1 至 9，每种四张，共 108 张。没有风牌、三元牌、花牌、赤宝牌、王牌、宝牌或立直机制。

庄家起手 14 张，其余玩家 13 张。开门只使用一组两骰：点数和定开门方，较小点数定幢数（对子就取该点）。杠后补牌从剩余牌墙尾端取得。

## 2. 定缺与强制打缺

发牌后，每名玩家直接从万、筒、索中宣告一门定缺花色；T/TFMJ 默认没有换三张阶段。之后必须将这一门清空。

只要手里仍有定缺牌，轮到自己时就必须优先打定缺牌，不能先打另外两门。和牌时，暗手与副露合计都不能再含自己宣告的定缺花色。

## 3. 行牌、鸣牌与优先级

本 profile 允许碰、大明杠、暗杠、加杠、荣和、自摸，**不允许吃**。

荣和优先于碰和大明杠。同一张弃牌允许多家荣和。加杠在成立前可以被抢杠；用于加杠的第四张必须是该回合刚摸到的牌。

所有杠都要求仍有补牌。最后四次摸牌不形成默认强制和牌或全面禁鸣边界。

## 4. 血战到底

有人和牌不会立即结束本手。和家先完成结算并退出活动状态，剩余玩家沿用同一牌墙和当前分数继续打，直到只剩一名活动玩家，或牌墙耗尽。因此一手最多可产生三名和家。

同一张弃牌多响时，每名合法荣家都单独获得支付。已经和牌退出的玩家，不再参加后续和牌、杠分或荒牌转移。

## 5. 过胡

任何阶段都可以放弃一次合法和牌。过胡后，到自己下一次摸牌前，不能再和相同或更低番数的牌；若后来出现严格更高番数，仍可和牌。平胡为 0 番，因此过平胡后仍可和 1 番大对子。

本可荣和却选择碰或杠，也按过胡处理。比较使用自摸 `+1` 支付之前的实际番数；0 番与 1 番是不同档，不能折叠。

## 6. 牌墙末段

T/TFMJ 没有“末四张必须胡”。玩家仍可过荣或自摸；只要仍有合法补牌，碰杠也不因剩 4 张而被一刀切关闭；超时托管不会强迫玩家和牌。只有真正的最后一张及其弃牌获得“海底”加番。

## 7. 和牌牌型与番种

合法手牌必须已经清空本人定缺花色，并组成四面子一对或七对。用于支付的总番封顶为 3。

| 番种 | 原始番数 | 本插件解释 |
| --- | ---: | --- |
| 平胡 | 0 | 普通和牌，基础分 1 |
| 对对胡 | 1 | 四组刻子 / 杠子加一对 |
| 清一色 | 2 | 所有牌只来自一门花色 |
| 七对 | 2 | 七组门清对子；四张相同可作两对 |
| 根 | 每根 +1 | 四张相同即一根；七对中的四张也叠加根 |
| 金钩钓 | +1 | 四组固定副露的对对胡，单钓雀头 |
| 海底 | +1 | 最后一张自摸或最后弃牌荣和统一使用该标签 |
| 杠上花 | +1 | 杠后补牌自摸 |
| 杠上炮 | +1 | 荣和杠后立即打出的牌 |
| 抢杠胡 | +1 | 荣和别人尝试加杠的牌 |

基础牌型取最高一项，再叠加合法加番因素，并把支付总番封顶为 3。将对、龙七对、双龙七对、豪华龙七对不是 T/TFMJ 的独立番种：全 2/5/8 刻子按大对子计；带根七对显示为“七对 + 根”。

## 8. 和牌支付

令 `P = 2^min(总番, 3)`，基础支付单位为 1、2、4、8。

- **荣和：** 只有放铳者向和家支付 `P`。
- **自摸：** 每名仍在活动状态的对手各向和家支付 `P + 1`。
- **多响：** 放铳者分别向每名最终荣家支付各自的 `P`。

## 9. 杠分与呼叫转移

杠分立即结算并保持零和：

- **暗杠：** 每名其他活动玩家付 2；
- **大明杠：** 仅提供弃牌的玩家付 2；
- **加杠：** 每名其他活动玩家付 1。

杠牌者若紧接着打牌放铳，该次及连续杠的全部收入转给和家，原付款人不退款。多家荣时，每家取得 `ceil(连续杠收入 / 荣家数)`，不能整除的差额由放铳者补足；杠后普通弃牌无人和则清空该连杠链。牌墙耗尽时，未听玩家逐笔退回本手取得的全部杠收入。

## 10. 荒牌：查花猪与查叫

牌墙耗尽时，只检查仍未和牌的活动玩家。

1. 所有活动玩家都按结算瞬间的暗手与副露重新计算听牌，不使用旧听牌缓存，也不会把物理上不存在的第五张牌当成等待。
2. 最终仍自然持有定缺牌者按未听参加查叫，不因最终快照自动触发固定 16/48 分花猪罚。
3. 每名未听者向每名听牌者支付该听牌者的最高理论和牌单位，最高 8。
4. 未听者先退回本手全部杠收入，再执行查叫。

现实比赛中的违规花猪需要裁判与违规历史，并可能进入外部罚分池；不能仅凭正常荒牌时未打完定缺牌推断。

## 11. 赛长与庄家

T/TFMJ 的一局通常为 50 分钟或 8 副，赛事手册可改为 6 副。MahjongPaper 房间默认 8 副，并从净分 0 显示累计；暂未实现完整的 8 局 × 8 副赛事排名层或按时间终止。通用分数、赛长覆盖属于自定义房间，不是严格预设。

其他通用立直选项不会改写本 profile：四川平胡 0 番、血战多响、不可吃、无赤牌、无宝牌保持固定。

下一手庄家按上一手结果决定：

- 第一名和家成为下一庄；
- 若第一次和牌事件就是多响，则由放铳者坐庄；
- 无人和牌则原庄保留。

默认界面显示 **第 1 副～第 8 副**，不再借用日麻“东一～南四”局名；实际庄家位置由独立状态维护，不与副数绑定。

## 12. 认可规则之间的边界

默认 profile 不混合冲突规则。MIL 对杠上炮退款和固定外部花猪罚有不同定义；“天府龙牌”地方赛事另有末四张强制和及不同引杠支付。这些若实现，必须使用独立命名的 profile；`SICHUAN_TOURNAMENT` 不是二者的模糊别名。

## 14. 实现与回归契约

本页记录 T/TFMJ 权威基线下的默认 profile。规则变更只有在控制器 / 规则引擎、中英日文档和保护该行为的测试同步更新后才算完成。

- 核心实现：`GbTableRoundController.java`、`SichuanPreparationFlow.java`、`DefaultSichuanRulesEngine.java`、`SichuanHuEvaluator.java`。
- 主要回归契约：`SichuanRulesEngineTest`、`SichuanRealWorldFanCoverageTest`、`SichuanRuleInvariantTest`、`GbTableRoundControllerTest`、`SessionActionDeadlineCoordinatorTest`、`SessionRulePresetResolverTest`。
- 番数不变量：平胡 0、大对子 1、清一色与七对 2；加番后总番封顶 3，因此最高基础支付单位为 8。
- 杠分不变量：暗杠向每名其他活动玩家收 2；大明杠只向提供弃牌者收 2；加杠向每名其他活动玩家收 1。
- 流程不变量：直接定缺、不可吃、默认无末四强制和、呼叫转移、查叫与血战继续属于 T/TFMJ profile；默认房间为 8 副。
